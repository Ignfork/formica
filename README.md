# Formica ($FORMICA)

Single-file site: `index.html` (no build step). Upload it to any static host (Vercel, Netlify, GitHub Pages).

## Edit before launch
Open `index.html`, find `CONFIG` at the top of the script:
- `xUrl` / `xHandle`: your X account (links show a "coming soon" toast until set)
- `ca`: the $FORMICA mint once live (turns on the pump.fun link)
- `launchUrl`: where the launch button sends people once launches are real

## Notes
- All coins, crews and numbers are labelled SAMPLE; the launch form runs a preview only.
- All ant art is original pixel art drawn in code.
